\chapter*{摘要}
隨著車載資訊系統與無線連線功能普及，車輛 Wi-Fi 介面可能成為攻擊者進入車內網路或干擾車載服務的入口。本研究針對車聯網測試場域，設計並實作一套以 Web 為操作介面的 Wi-Fi 資安測試平台，整合無線網路掃描、安全組態稽核、授權攻擊情境、無線入侵偵測（Wireless Intrusion Detection System, WIDS）及可追溯的測試紀錄。

本平台採用 Flask 與 Socket.IO 建立前後端架構，後端負責串接無線掃描、測試工具與封包監控元件，並在缺少實體測試工具時提供模擬輸出，以支援開發與展示。系統可針對 WPS、WPA3／802.1X、PMF（802.11w）、SSID 廣播及用戶端隔離等項目進行初步稽核，並以 deauthentication、Rogue AP、WPS 測試、握手封包擷取與 PMF probe 等情境評估防護能力。

目前成果以功能原型與流程驗證為主，實體 T-BOX 測試、量化效能數據及真實工具輸出仍需於授權實驗環境中補充。

\noindent\textbf{關鍵詞：}車聯網、Wi-Fi 資安、WIDS、滲透測試、UN R155、ISO/SAE 21434

\chapter{緒論}
\section{研究背景與動機}
車聯網、T-BOX 與車內 Wi-Fi 逐漸成為車輛服務的重要連線介面。無線介面的便利性同時擴大了未授權存取、管理框架干擾、弱認證與 Rogue AP 等攻擊面。UN R155 與 ISO/SAE 21434 亦要求製造商建立資安風險管理、驗證測試與證據追溯流程。

現有 Wi-Fi 資安測試往往依賴多個命令列工具，測試人員需要人工切換掃描、稽核、攻擊與監控流程，結果也容易分散在不同終端機輸出中。因此，本研究將常用測試功能整合至單一 Web 流程，降低操作差異並改善結果留存。

\section{問題陳述}
車載 Wi-Fi 測試面臨測試流程分散、攻擊情境難以重複、偵測結果缺少一致格式，以及合規證據不易追溯等問題。本研究聚焦於如何以威脅模型連結 UN R155 要求、Wi-Fi 測試情境與 WIDS 偵測結果。

\section{研究目的與貢獻}
\begin{enumerate}
  \item 建立符合車載 Wi-Fi 測試需求的自動化測試框架。
  \item 建立涵蓋被動掃描、組態檢測、主動攻擊模擬與 WIDS 的整合流程。
  \item 將測試情境與 UN R155／ISO/SAE 21434 的資安驗證需求建立對照關係。
  \item 建立具時間戳、分類與 JSONL 格式的測試稽核軌跡，支援後續合規證據整理。
\end{enumerate}

\section{論文架構}
本論文共分為七章。第一章說明研究背景、問題與貢獻；第二章回顧車聯網資安標準與相關研究；第三章提出威脅模型與平台架構；第四章說明研究方法與核心實作；第五章呈現實驗設計與成效評估；第六章討論合規貢獻與限制；第七章總結研究成果並提出未來工作。

\section*{研究範圍與限制}
本研究對象為 ARTC T-BOX 測試台、實驗室 AP 與明確授權的無線目標，聚焦 Wi-Fi 層及其與車載測試流程的介面，不涵蓋完整車內 CAN 或車載乙太網路漏洞分析。現階段部分模組在缺少 Kali／Parrot 工具或監聽模式硬體時採用模擬資料，論文實驗章將分開呈現模擬結果與實體結果。所有攻擊情境僅能在書面授權的隔離環境執行。

\chapter{威脅建模與系統架構}
\section{測試目標與環境定義}
本研究測試目標為 ARTC T-BOX 與其車載 Wi-Fi 服務，測試環境由測試主機、無線介面、受測 AP／T-Box、隔離網路與紀錄系統構成。測試活動限於具備書面授權的設備與網段。

\section{威脅模型}
依照資產、信任邊界、攻擊者能力與攻擊面建立威脅模型。資產包含 Wi-Fi 認證資訊、車載服務可用性、管理框架完整性與測試證據；攻擊者模型區分鄰近無線攻擊者與可接近測試網路的攻擊者，並將被動偵察、組態弱點、管理框架干擾及 Rogue AP 納入分析。

\section{測試平台與 WIDS 系統架構設計}
系統由瀏覽器、Flask 後端、掃描模組、安全稽核模組、攻擊工作管理器、WIDS 監控器與 JSONL 紀錄器組成。瀏覽器透過 REST API 發出控制請求，再透過 Socket.IO 接收工作狀態、即時輸出與 WIDS 事件。

\chapter{討論}
\section{研究成果對 UN R155 合規性之貢獻}
逐項回應第一章研究目的，並以第三章功能需求及第五章實驗結果作為證據。

\section{測試框架之侷限性與挑戰}
目前外部工具輸出尚未完整結構化，WIDS 多數事件仍為骨架或模擬輸出，且尚未具備角色型身分驗證、正式報告匯出、日誌防竄改與集中管理機制。

\section{合規與實務應用意義}
本平台可作為 UN R155／ISO/SAE 21434 測試證據產生工具的原型，但仍需由組織流程、風險分析、權限控管與正式審查補足完整合規要求。

\chapter{結論與未來展望}
\section{研究總結}
本研究完成一套車聯網 Wi-Fi 資安測試平台原型，將掃描、組態稽核、授權測試、WIDS 監控與稽核紀錄整合至單一 Web 流程。正式結論待完成實體測試後，加入量化數據與限制條件。

\section{未來工作}
\begin{enumerate}
  \item 完成 wifite2、封包擷取檔與測試結果的結構化解析。
  \item 補充 DragonBlood、降級攻擊與真實 deauth reason-code 分類。
  \item 完成 beacon flood、握手異常及 Rogue AP 的 Scapy 偵測器。
  \item 加入角色型身分驗證、權限控管與安全命令參數驗證。
  \item 建立 PDF／UN R155 證據包匯出與報告模板。
  \item 於 ARTC T-BOX 測試台進行多版本韌體、多種加密設定與重複樣本驗證。
\end{enumerate}
